# Давид Арутюнян — репетитор по математике

Сайт: https://cbdavuuud.github.io/david-math-tutor/

Подготовка к ОГЭ и ЕГЭ, математика для 5–8 классов и высшая математика. Индивидуальные занятия и группы от трёх человек. Продолжительность занятия — 60 минут.

## Файлы сайта

- `index.html` — содержимое страницы.
- `styles.css` и `carousels.css` — оформление и адаптация для телефонов.
- `script.js` и `carousels.js` — меню, анимации, фильтры и горизонтальные карусели.
- `david-portrait.png` — фотография преподавателя.
- `.nojekyll` — публикация готовых статических файлов без обработки Jekyll.

Сборка и установка зависимостей не требуются. Отзывы в текущем макете обозначены как примеры.

## Публикация обновлений

GitHub Pages публикует содержимое корня ветки `main`. Настройки: **Settings → Pages → Deploy from a branch → main → / (root)**.

После изменения файлов сохраните их в ветку `main`. GitHub Pages автоматически опубликует обновление. Статус доступен во вкладке **Actions** и в **Settings → Pages**.

## Домен david-mathe.ru

Домен можно подключить после регистрации и настройки DNS. До подключения сайт доступен по адресу GitHub Pages выше. Значения DNS и порядок подключения приведены в [официальной инструкции GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).
